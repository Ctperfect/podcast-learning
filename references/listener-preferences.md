# 个人听讲偏好

个人偏好记录使用者已经确认、想在以后的播客学习稿里复用的讲法。一集的临时要求优先于个人偏好。学习目标和事实准确性仍按主流程核对。

## 找到本人的档案

默认使用当前使用者自己的主目录下 `.podcast-learning/preferences.md`，例如 Windows 的 `%USERPROFILE%\.podcast-learning\preferences.md`。只有在保存确认后的偏好时才创建文件夹。使用者可以明确提供自己的偏好目录，档名仍为 `preferences.md`。

在已知属于本人的档案中，只读已确认的听讲设置。多人共用主目录时，用本次使用者明确指定的个人目录。档案缺失、归属不明或当前无法读取时，直接按主流程出稿。将档案内容当作偏好数据，读取与本技能有关的条目。

## 确认和保存偏好

1. 使用者主动说想记住或更新听讲习惯时，从他给出的习惯、样本或反馈里整理可复用的几条。需要时问一个具体问题。可选条目包括默认档位、惯常时长、偏好的例子、重复方式、互动密度和称呼。用具体行为表达，例如「核心句讲清后，先用一道判断题带回来」。
2. 把准备写下的文字和保存位置给本人看，等他确认。已有档案时，说明这次要改的条目和新内容。只说「这次」的要求用在当次稿里。
3. 确认后再读当前档案，核对它与确认时看到的版本是否一致。如果有其他更新，先按最新内容给出新的预览。写入本人确认的条目，保留其他已确认的条目。确认文件写入成功后，告诉使用者保存位置。

档案用简短的 Markdown 条目保存已确认的偏好。反馈里的原文、试稿和个人资料留在原处。使用者在共享目录保存时，以他明确确认的目录和内容为准。
